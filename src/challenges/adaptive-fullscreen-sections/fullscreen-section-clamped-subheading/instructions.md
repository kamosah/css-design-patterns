## Problem: Fullscreen Section with Clamped Subheading

Try to limit a subheading to two lines with ellipsis and center the content.

## Problem description

Given a `<section class="fullscreen-section">` containing an `<h1>` and a `<p class="subheading">`, write CSS to ensure the subheading never takes more than two lines — extra text should show an ellipsis. Center all content.

## Goal

Ensure the layout remains visually clean, regardless of subheading length.

## Constraints

- No JavaScript is allowed.
- Do not modify the HTML.
