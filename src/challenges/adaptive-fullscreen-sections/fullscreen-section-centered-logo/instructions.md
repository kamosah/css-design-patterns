## Problem: Fullscreen Section with Centered Logo and Subtext

Try to vertically stack and center a logo and subtext with spacing in a fullscreen section.

## Problem description

Given a `<section class="fullscreen-section">` containing an `<img class="logo">` and a `<p class="subtext">`, write CSS so the logo and subtext are centered, stacked vertically, with spacing between them, regardless of screen size.

## Goal

Stack logo and subtext in a perfectly centered column, with 24px between them.

## Constraints

- No JavaScript is allowed.
- Do not modify the HTML.
