# Sticky Sidebar Navigation

Given a two-column layout with a `<nav class="sidebar">` and a `<main class="content">`, apply CSS so that the sidebar stays pinned to the top of the viewport as the user scrolls through the long content area.

## Goal

Use only CSS to keep the sidebar fixed in place while the main content scrolls beneath it.

## Constraints

- Use CSS `position: sticky`
- No JavaScript allowed
- The flex layout must remain intact — do not use `position: fixed`
