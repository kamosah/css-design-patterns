# Persistent Sticky Footer

You have a web page with dynamic content of variable height inside a `.content` container. Implement a footer that stays out of view until the user reaches the bottom of the content — from that point on, the footer should stick to the bottom of the browser window while scrolling.

## Goal

Make the `.sticky-footer` element stick to the bottom of the viewport once the user scrolls past the main content using only CSS.

## Constraints

- Use CSS `position: sticky` with `bottom: 0`
- No JavaScript allowed
- Do not change the HTML structure beyond adding classes
- Must work in Chrome, Firefox, and Edge
