## Problem: Accessible Input Focus Highlight

easy · 15 min · Try to add a custom focus highlight to a text input for clear accessibility feedback.

## Problem description

Given an HTML page with a `<input class="accessible-input" type="text" placeholder="Your name">`, write CSS to meet the following requirements:

1. When the input is focused (for example, using the **Tab** key), it should display a clear, visible box-shadow.
2. The box-shadow must be `0 0 0 3px rgba(38, 132, 255, 0.5)` (a soft blue glow).
3. The default browser outline should not appear; only your custom box-shadow should show.

## Goal

Ensure the input field has a custom, visually clear focus indicator to make navigation and form completion accessible to keyboard users.

## Constraints

- Use CSS only.
- Do not use JavaScript or change the HTML structure.
