# Two-Column Responsive Layout

Given a series of content cards inside a container, implement a two-column grid that collapses to a single column on narrow viewports.

- Displays two equal-width columns on viewports wider than 600px
- Collapses to a single column on viewports 600px wide or narrower

## Goal

Write CSS in `styles.css` to define the grid container and apply a media query that adjusts the grid layout based on viewport width.

## Constraints

- Use CSS Grid for layout
- Apply one media query only at `max-width: 600px`
- Gap between columns and rows should be `1rem`
- No JavaScript allowed
