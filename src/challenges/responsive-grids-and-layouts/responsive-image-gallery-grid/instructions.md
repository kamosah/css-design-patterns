# Responsive Image Gallery Grid

Given a collection of thumbnail images inside a `.gallery` container, implement a responsive grid that adapts to the available viewport width without any media queries.

- Displays as many columns as possible with each thumbnail at least 150px wide
- Automatically wraps thumbnails to new rows when they overflow
- Maintains a 10px gap between images

## Goal

Write CSS in `styles.css` to configure the `.gallery` container so it adapts fluidly to the viewport width, resizing and wrapping thumbnails without any media queries.

## Constraints

- Use CSS Grid only
- Do not use media queries
- Set thumbnail column width with a minimum of 150px and a maximum of `1fr`
- Keep a 10px gap between items
