# Accessible Radio Button Focus

## Problem

Given an HTML page with an `<input class="accessible-radio" type="radio" name="choice">`, write CSS to meet the following requirements:

- When the radio button is focused (for example, using the Tab key), it should display a visible blue focus ring.
- The focus ring must be a `2px solid #2684FF` outline, offset by `2px` from the radio button.
- The default browser outline should not appear; only your custom focus ring should show.

## Goal

Provide a clear, custom focus indicator for the radio button to make it accessible for keyboard users.

## Constraints

- Do not use JavaScript or change the HTML structure.
