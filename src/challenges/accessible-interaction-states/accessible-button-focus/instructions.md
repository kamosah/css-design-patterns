## Problem: Accessible Button Focus Indicator

easy · 15 min · Try to add a custom visible focus outline to a button for better accessibility.

## Problem description

Given an HTML page with a `<button class="accessible-btn">Click Me</button>`, write CSS to meet the following requirements:

1. When the button is focused (for example, using the **Tab** key), it should display a clear, visible outline.
2. The outline must be `2px solid #2684FF`.
3. The outline should be offset by `2px`, so it sits outside the button's border.
4. The default browser outline should not appear; only your custom outline should show.

## Goal

Ensure the button has a custom, visually clear focus indicator for accessibility, making keyboard navigation and usage more user-friendly.

## Constraints

- Use CSS only.
- Do not use JavaScript or change the HTML structure.
