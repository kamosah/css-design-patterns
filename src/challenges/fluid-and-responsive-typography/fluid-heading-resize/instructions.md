# Fluid Heading Resize

Given a heading element (`<h1>`), implement CSS rules so that its font size scales smoothly between a defined minimum and maximum as the viewport width changes.

## Goal

Use CSS properties to ensure the heading text remains legible and aesthetically pleasing across a range of screen sizes by implementing fluid typography.

## Constraints

- Do not use JavaScript.
- Support all modern browsers.
- The font size must scale between a minimum of **24px** and a maximum of **48px**.
- Viewport widths in scope are **320px – 1200px**.

## Hint

Look into the CSS `clamp()` function — it lets you set a value that scales between a floor and a ceiling based on a viewport-relative unit.
