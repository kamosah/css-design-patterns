# Fluid Button Label

Given a button element (`<button>`), write CSS rules that enable its font size to scale smoothly between a defined minimum and maximum as the viewport width changes.

## Goal

Use CSS to ensure the button label remains legible and proportional across a range of screen sizes by implementing a fluid font sizing approach without JavaScript.

## Constraints

- The solution must use an external stylesheet `styles.css`.
- Do not use JavaScript.
- Support all modern browsers.
- The button font size must be at least **16px** and at most **24px**.
- Viewport widths in scope are **320px – 1200px**.
