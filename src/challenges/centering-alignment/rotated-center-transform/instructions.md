## Problem: Center a Rotated Element

Center a rotated element visually within its container using absolute positioning and CSS transforms.

## Problem description

A `.wrapper` div is `200×200px`. Inside it, `.rotated` contains a star (★) and is already set to `position: absolute` with a `rotate(45deg)` transform. As-is, the element sits at the top-left corner of the container instead of its center.

## Goal

Position `.rotated` so it appears perfectly centered (both horizontally and vertically) inside `.wrapper`, while still being rotated 45 degrees.

## Constraints

- You may only modify `.rotated` in `styles.css`.
- Do not change the HTML.
- Do not use Flexbox or Grid on `.wrapper`.
