## Problem: "Space-Between" + Centering Three Items

Try to use Flexbox to align three icons at the left, center, and right edges of a toolbar.

## Problem description

A `.toolbar` contains three child icons: `.left`, `.center`, and `.right`. The task is to position the first icon flush left, the last icon flush right, and the middle icon exactly at the horizontal midpoint — all within a single Flex container.

## Goal

Distribute the icons at 0%, 50%, and 100% across the toolbar's width without using multiple containers or extra HTML wrappers.

## Constraints

- Only CSS modifications to existing elements are allowed — no new HTML elements or JavaScript.
