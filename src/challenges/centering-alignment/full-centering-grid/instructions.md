## Problem: Centering via CSS Grid

Try to center an element perfectly within a container using CSS Grid's alignment properties for both axes.

## Problem description

A grid container measures `200px` by `200px` and contains a single child `.centroid`. The task is to center the child both horizontally and vertically within the container using a single CSS Grid property.

## Goal

Position `.centroid` at the exact center of the grid container on both axes.

## Constraints

- Only CSS changes are allowed; the HTML must remain unchanged and JavaScript cannot be used.
