## Problem: Inline-Block Group Centering via text-align

Try to center a group of inline-block elements within a container using the `text-align` property.

## Problem description

A `.wrapper` element is 500px wide and contains two inline-block `.item` elements. The task is to center the group of `.item` elements within the wrapper so they appear together in the middle.

Write CSS to meet the following requirements:

1. The `.item` elements must remain `display: inline-block`.
2. Both items should appear centered as a group within the `.wrapper`.

## Goal

Group-center the inline-block items within the wrapper using only `text-align` on the parent.

## Constraints

- You may only apply CSS to existing elements — no extra wrappers or scripts.
