## Problem: Paragraph Rhythm Setter

Define a CSS custom property for the rhythm unit and use it to set the line-height and bottom margin of paragraphs, ensuring uniform vertical flow.

## Problem description

A page contains three paragraphs. The `--rhythm` variable is already defined in `:root` and the base `font-size` is set on `body`. Your task is to apply the rhythm unit to the paragraphs so their line spacing and bottom margin both align to the same vertical grid.

## Goal

Use the `--rhythm` custom property to set both `line-height` and `margin-bottom` on the `p` selector.

## Constraints

- Use only the `--rhythm` custom property already defined in `:root` — do not introduce new values.
- No JavaScript allowed.
- Do not modify the HTML.
