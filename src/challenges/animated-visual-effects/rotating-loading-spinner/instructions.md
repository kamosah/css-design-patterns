# Rotating Loading Spinner

Given an HTML page containing a `<div class="spinner"></div>` element, write CSS to build a circular loader that rotates indefinitely.

## Goal

Style the `.spinner` as a circular element and apply a continuous rotation animation using only CSS.

## Constraints

- Use only CSS — no JavaScript
- `width` and `height`: `50px`
- `border`: `5px solid #ccc`
- `border-top`: `5px solid #333` (creates the spinner arc effect)
- `border-radius`: `50%`
- `@keyframes` name must be `spin`
- Animation duration: `1s`
- Animation timing: `linear`
- Animation iteration count: `infinite`
