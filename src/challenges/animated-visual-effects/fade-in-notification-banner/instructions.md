# Fade-In Notification Banner

You have a `.notification-banner` element that should smoothly appear when the page loads.

## Goal

Use CSS `@keyframes` and `animation` to fade the banner in from fully transparent to fully visible over 5 seconds when the page loads.

## Constraints

- Use `@keyframes` to define the fade animation
- Use `animation` shorthand with `ease` timing and `forwards` fill mode
- No JavaScript allowed
- The element must start invisible and end fully visible
